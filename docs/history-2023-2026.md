## Tres estados y procedencia

- **Cotejada documentalmente:** enunciado, cuatro alternativas, sección, numeración, reserva, clave del mismo ejercicio y correspondencia A/B comprobados. Su procedencia se muestra aparte: institucional o copia corroborada.
- **Respuesta final y anulaciones acreditadas:** exige evidencia oficial suficiente del alcance por pregunta y una revisión concordante. No exige que exista un documento independiente llamado «certificado de firmeza». Actualmente no hay preguntas en este estado.
- **Pendiente de cotejo adicional:** borradores o evidencias incompletas/alteradas. No entran en las frecuencias documentales.

El corpus descriptivo admite el primer estado y muestra sus límites. El corpus estricto de simulacros corregibles y evaluación predictiva exige el segundo. Cambiar enunciado, opciones, respuesta, fuente, mapa A/B o corroboración rompe la huella documental. No se puede convertir una copia secundaria en pregunta final por editar una casilla.

Las URLs exactas de cada PDF y sus huellas están en el catálogo y en `bank.json`; no basta el nombre del proveedor. Coincidir entre sitios no prueba independencia editorial ni identidad con el original institucional: `origin:secondary`, `verified:false`, `definitive:false` permanecen así.

`python/verify_history.py` compara pypdf y pdfplumber, restringe la extracción a conocimientos, exige cuatro alternativas y 105 números consecutivos por forma, identifica las cinco reservas y coteja la copia de contraste. Las claves se transcribieron visualmente para ambos modelos —1.200 respuestas ordinarias más reservas— y se comprobaron con los mapas A/B; no se confió en OCR de baja calidad. Las transcripciones completas son inspeccionables en `key-transcriptions.json`. La revisión visual fue realizada en este flujo, no por dos revisores humanos independientes.

## Errores encontrados y corregidos

1. Cabeceras «Resolución núm.» contaminaban algunas opciones D de 2024: se amplió la exclusión de cabeceras del extractor y se verificó el banco completo con ambos motores.
2. En 2025 A58/B25 el original B imprime «dministraciones». Se conserva el error literal y se documenta como excepción de emparejamiento, sin corrección silenciosa. [Página de evidencia](../data/research/history/2025-B-page6.png).
3. Ambos extractores separaban «ante» como «ant e» en 2024 3A78. Se cotejó visualmente el PDF y se corrigió sólo ese espacio de extracción, conservando fragmento previo, motivo y [página de evidencia](../data/research/history/2024-3A-page13.png). Así se recupera una repetición literal real, sin borrar puntuación o espacios indiscriminadamente.
4. Se corrigieron fechas/modelos contradictorios de 2023 y la atribución incorrecta del ejercicio 1 de 2024 a una jornada independiente.
5. No se atribuye a preguntas de estructura ministerial de 2023 un real decreto de 2024. Su versión histórica concreta sigue pendiente.
6. Se mantienen las discrepancias anteriores de 2026, incluida la errata de resolución en el encabezado de clave y «Noveno»/«Noveno.» de A28/B62.

No se descartó ninguna pregunta ordinaria por un supuesto acuerdo de anulación no encontrado. Las reservas siguen inactivas. Las propuestas normativas ambiguas quedan fuera de las fichas.

## Estadísticas que funcionan

Dashboard, explorador, patrones y fichas se calculan desde el corpus admisible, no desde cifras fijas. Cada relación permite inspeccionar los enunciados, opciones y PDF de ambos modelos.

- Temas: Derechos Humanos **80**, Procesal Penal **68**, Constitucional **58**, sobre 700 ordinarias.
- Normas citadas: Código Penal **43**, Constitución **40**, Ley de Enjuiciamiento Criminal **33**, Código Civil **29**, Ley 39/2015 **20**. Son identificaciones del encabezado revisado; no implican artículo verificado en todas ellas.
- **132 preguntas** con alguna referencia específica cotejada; **121 fichas de artículos numéricos**. Se agregan por norma y artículo, manteniendo apartados en el detalle. Artículo 9 de la LO 1/1982: **3 apariciones** en 2023, 2024 y 2026; artículo 23 de la Ley 40/2015: **2**. Se incorporan 60 localizaciones históricas nuevas con bloque BOE y versión publicada y vigente antes del examen.
- **2 grupos de repetición literal entre años**: internamiento cautelar (2023 2A93 / 2024 3A92) y quejas (2024 3A78 / 2026 A76).
- **12 familias conceptuales revisadas** reaparecen entre años; **6** tienen años consecutivos. Tutela del honor: **4 apariciones**, quejas en Guardia Civil: **3**, paradas del transporte de explosivos: **2**. Una familia puede reunir distintos subaspectos: se conserva el detalle específico, sin afirmar identidad jurídica de todas las formulaciones.
- Comparación de frecuencias histórica/reciente (2025–2026), distribución anual, sesiones de aparición y periodos sin nueva observación, con denominadores explícitos.

La taxonomía específica cubre **176/700 preguntas** y 158 conceptos distintos. Los grupos se revisaron a posteriori para iniciar el estudio de repeticiones. Las 524 pendientes no se convierten en un concepto genérico y permanecen en los denominadores. La frecuencia conceptual y su ranking son parciales, con sesgo de cobertura; no constituyen un ranking exhaustivo. No se han acreditado retiradas concretas del programa vigente: se muestran como pendientes, sin inventar que algo dejó de entrar. Las versiones BOE históricas no certifican por sí mismas vigencia para 2027.

## Prioridad y evaluación temporal

Se separan recuento observado, puntuación heurística y probabilidad. La heurística está disponible para ordenar estudio con varios años, explica sus componentes, muestra fuentes y cobertura, y no añade puntos por tiempo sin aparecer. **Toda probabilidad sigue siendo `null`.**

La evaluación estricta está implementada, pero no puede producir conclusiones: faltan respuestas finales y fechas históricas de publicación acreditadas. No se reemplazan estas fechas en la base por la fecha del examen ni por la descarga actual.

Se puede seleccionar una **reconstrucción exploratoria documental**: sólo usa exámenes anteriores al año objetivo y supone disponibilidad desde su celebración cuando no consta publicación. Las fechas conocidas posteriores al corte siempre se excluyen. Ese supuesto no autentica las copias ni demuestra que sus versiones corregidas estuvieran disponibles entonces. El universo de conceptos del ranking procede sólo del entrenamiento; las etiquetas y la selección de familias, sin embargo, se han revisado retrospectivamente, con riesgo de sesgo por información futura. Se necesita una taxonomía congelada y periodo externo nuevo.

## Reproducir, revisar y conservar

```bash
npm ci
cp .env.example .env.local
npm run dev
# Abrir http://127.0.0.1:3000
```

El arranque carga el banco sellado sin Python. Para repetir la extracción de los PDF retenidos:

```bash
python -m venv .venv
.venv/bin/python -m pip install -r python/requirements.txt
.venv/bin/python python/verify_history.py
npm run data:apply-verified
npm run data:verify
npm test
npm run typecheck
npm run build
npx tsx scripts/history-report.ts
```

No se necesita red para repetir el cotejo histórico ni API de IA. Las nuevas propuestas normativas requieren XML histórico BOE y revisión humana; no se autoaprueban por similitud. Ver [README](../README.md) y [método](methodology.md).

La comprobación de conservación compara todas las entidades por identificador y los originales por SHA-256. Se mantienen los paquetes previos y una copia transaccional de la base anterior. El ZIP de esta fase contiene código, evidencias y PDF, sin credenciales, dependencias ni base personal; la base se reconstruye al arrancar. El historial Git conserva también las versiones previas de código y documentación.

Pendiente: autenticación institucional de las copias, acuerdos de corrección/anulación con alcance suficiente, fechas de publicación, revisión de conceptos y vigencia para 2027. PostgreSQL/Supabase y Safari físico requieren pruebas en el entorno del usuario. No hay hosting HTTPS contratado/configurado: GitHub publica el código; la web se abre localmente o se despliega en un servidor Node con los secretos descritos en el README.
